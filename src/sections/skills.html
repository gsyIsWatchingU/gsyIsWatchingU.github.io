PART 01 / THE DIFFERENCE

AI Agent Harness

模型负责生成，我负责让它在生产环境可用、可运营、可控成本。

上下文与记忆

窗口不是越大越好——分层管理短期对话、长期记忆与 RAG 检索，防止 context rot。

  • Context Engineering
  • Memory
  • RAG

提示词与输出约束

Schema 约束 + 解析校验 + 自纠错兜底，Prompt 版本化可灰度，改了知道为什么变好。

  • Structured Output
  • JSON Schema
  • Prompt Versioning

工具调用与智能体编排

最大敌人是空转——硬步骤上限、重复调用检测、Plan/Execute 拆开，让模型动手不绕圈。

  • Tool Calling
  • MCP
  • ReAct
  • Loop Guard

评测与监控

线上失败 case 反哺评测集，全链路 Trace 可复现非确定性 bug，定期冒烟防模型静默漂移。

  • Eval / Regression
  • Tracing
  • LLM-as-Judge
  • Drift Alert

安全与可靠性

防 RAG 间接注入、审批按风险分级、重试加并发上限防 storm、高风险操作跑在沙箱里。

  • Injection Defense
  • Approval Gate
  • Sandbox
  • Circuit Breaker

推理成本工程

大小模型按任务路由，语义缓存设 TTL，Token 预算硬限制——不让简单问题烧大模型的钱。

  • Model Routing
  • Semantic Cache
  • Token Budget

PART 02 / THE FOUNDATION

AI 全栈

从界面到数据，独立把智能能力端到端做成可交付产品。

端到端产品交付

从交互到上线一个人闭环：不依赖前后端分工，流式 UI、接口、数据库、部署自己串完。

  • TypeScript / React
  • Node.js / Go
  • 独立交付

服务与数据建模

AI 生成的数据要可修正、可重跑、可追溯：用状态机区分"生成中/已确认/已修正"，缓存要分开确定性查询和概率性生成。

  • PostgreSQL
  • Redis
  • 缓存策略

实时与异步系统

流式输出用 SSE 就够，长任务丢队列异步跑并推进度；关键是背压——AI 生成速度可能快过客户端渲染，不能无脑推。

  • SSE
  • BullMQ
  • Backpressure

架构与持续交付

确定性代码单测全覆盖，模块边界控制变化范围；模型版本和代码一起版本化，出问题能一起回滚。

  • CI / CD
  • Docker
  • Testing

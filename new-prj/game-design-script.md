# 《雾钟孤院》完整游戏设计剧本

- 版本：1.1
- 定位：微恐、冒险、潜行、解谜、治愈
- 首发：小红书小工具、在线 Web
- 扩展：Steam 单机版

## 一句话提案

成年小川因一段错误记忆被困在二十四年前的雨夜。他以孩子的身体重返雾中孤院寻找妹妹，最终发现妹妹早已获救，真正被自己遗忘的人一直是他。

宣传句：**当钟声说还少一个，你要先学会把自己算进去。**

## 1. 游戏定义

| 项目 | 第一版：小红书 / Web | 第二版：Steam |
| --- | --- | --- |
| 产品形态 | 可独立通关的叙事短篇 | 在同一真相上扩写的完整单机游戏 |
| 目标时长 | 首轮 15～25 分钟，全收集 25～35 分钟 | 4～5 小时 |
| 核心结构 | 8 枚记忆余烬、3 座钟坛、3 段潜行、3 个结局 | 5 章、复合解谜、追逐、探索与完整尾声 |
| 操作 | 移动、观察、潜行、闪避、互动 | 增加攀爬、搬运、环境机关、同伴协作 |
| 叙事 | 无旁白，少量文字，环境讲故事 | 无强制长对白，关键节点短句配音 |
| 目标 | 建立世界观、角色记忆点和情绪闭环 | 深化人物、谜题、怪物来源与完整灾难真相 |

第一版不是试玩预告，而是一篇有完整起承转合的短篇。Steam 版扩写过程，不推翻第一版结局。

## 2. 核心体验

1. **怕，但愿意再向前一步**：没有战斗，玩家依靠观察、阴影和勇气穿过危险。
2. **先误解，再理解**：巡夜者最初像抓孩子的怪物，最终被还原为回头救人的照护者。
3. **每个机制都是叙事**：余烬是记忆，勇气是直面创伤的能力，钟坛是被卡住的回忆节点。
4. **治愈不是遗忘**：玩家不摧毁孤院，也不抹除过去，而是完成那次没能完成的回应。

## 3. 创作边界

- 保留暗黑童话、低视角、弱小主角和环境压迫感，但不复刻其他作品的角色、怪物、场景或情节。
- 不使用血腥、儿童受虐展示和廉价突脸惊吓。恐怖主要来自脚步、探灯、空间尺度和错误认知。
- 不把照护者塑造成纯恶人。怪物是记忆的变形，不是真实人物的道德定论。
- 不用大段文字解释真相。重要信息至少通过物件、动作和声音中的两种方式表达。
- 三条成长路线代表不同的应对方式，没有“选错人格”的惩罚。

## 4. 故事核心

### 4.1 主题

表层问题：妹妹当年去了哪里？

深层问题：一个幸存者是否愿意承认，自己也值得被救、被记住、继续生活？

### 4.2 主角为何被困

成年小川并非单纯“忘记过去”，而是用一套错误解释活了二十四年：

1. 他记得自己离开过接送队伍，却不记得原因，因此认定自己当年只顾逃跑。
2. 他记得林姨死在钟塔，却不记得林姨返回钟塔是为了救他，因此认定自己夺走了她的生路。
3. 他始终听见“还少一个”，却从未想过那个没有回应名字的人正是自己。

小川成年后不再使用“小川”这个童年称呼。他会下意识数清房间出口，从不让别人等自己，也从不参加任何需要逐一报到的场合。他看似生活正常，内心却一直停在孤院广播响起的 23:47。

他的潜意识给自己制定了一条无法完成的规则：**只有找到妹妹，才有资格离开。**

由于他相信妹妹已经死亡，这条规则注定无法完成。孤院因此成为不断重演的心牢：车永远开不走、宿舍永远没有熄灯、点名永远少一个。

### 4.3 现实起点

孤院即将拆除。失散儿童的旧档案重新开放，小满终于从曾用名记录里找到哥哥的地址，寄去一张拆除通知和一只新折的纸蛾，没有署名，只写：

> 今年，我在门口等你。

小川把它理解成死者的召唤，独自来到孤院。门外其实站着前来赴约的成年小满，但小川没有认出她，也没有真正看向她。他推开锈门后，现实废墟与创伤记忆重叠，身体在玩家视角中变回十一岁。

故事保持魔幻现实主义边界：心牢可以被理解为超自然空间，也可以被理解为小川在真实废墟中的创伤重演。游戏不替玩家下医学诊断。

### 4.4 故事真相

雾钟孤院共有二十四个孩子。暴雨夜，山体滑坡切断道路，接送车负责转移孩子。

小满因害怕钟声躲进宿舍衣柜。照护者林姨找到她，把她送上接送车。登车点名时，小川没有听见妹妹回应，趁车门关闭前跑回宿舍；他只看见空衣柜和一只纸蛾，误以为妹妹去了更深处，于是继续寻找。

接送车再次点名时，二十三个孩子已经到齐。广播里反复响起：“二十三，还少一个。”少的不是小满，而是小川。

林姨回到正在坍塌的钟塔寻找小川，并把他从排水检修道送出。林姨没有回来。小川在下游获救，却因高烧、惊吓与后续安置失去关键记忆。他一直相信自己丢下了妹妹，也默认妹妹已经死去。

小满其实活了下来。成年后，她多次回到封闭的孤院门口，留下小时候约定的纸蛾，希望哥哥有一天能认出它。

游戏发生在孤院拆除前夜。成年小川重返旧址，却以十一岁的身体进入记忆。烛蛾不是妹妹的亡魂，而是小满刚刚留在门口的纸蛾与小川记忆共同形成的引路者。

### 4.5 四层错误叙事

| 小川相信的故事 | 玩家前半程看到的“证据” | 完整真相 |
| --- | --- | --- |
| 我丢下了妹妹 | 空衣柜、纸蛾、关上的车门 | 小满已经上车，小川为了找她主动折返 |
| 巡夜者带走了她 | 长臂、探灯、抱走孩子的残影 | 林姨把小满送上车，又返回寻找小川 |
| 林姨因我而死，所以我不该被救 | 红围巾、坍塌钟塔、检修道 | 林姨的选择不是交换生命，而是照护者完成保护孩子的责任 |
| 点名缺少的是小满 | 二十三声回应、一个空位 | 车上已有小满，缺席者始终是小川 |

治愈不是一句“这不是你的错”直接说服主角，而是玩家亲手推翻四条错误信念。

### 4.6 最终升华

玩家一直以为任务是“找到妹妹”，最后才知道需要被找回的是主角本人。

终局不要求玩家杀死巡夜者或砸碎大钟，而是把刻有“小川”的名牌放回第二十四个位置，并亲口回应：

> 小川在。

这一声让持续多年的错误点名结束，也让成年小川第一次承认自己是幸存者，而不是事故里多余的那个人。

破晓后，小川不要求保留整座孤院。他与小满只取走二十四块名牌和林姨的红围巾，同意让危险建筑按计划拆除。允许旧址消失，不等于否认曾经发生的一切；真正需要保存的是名字、选择和仍活着的人。

## 5. 叙诡设计

叙诡核心不是“主角其实是鬼”，而是**主角在讲述自己的故事时，始终省略了自己**。玩家接受了他的省略，才会自然得出错误答案。

### 5.1 五层误导

1. **时间误导**：玩家以为正在经历灾难当夜，实际上现实已过去二十四年。
2. **身份误导**：玩家以为主角就是孩子，实际上操控的是成年小川的儿童自我。
3. **缺席者误导**：玩家默认“哥哥寻找妹妹”，因此把“少一个”自动理解成妹妹。
4. **怪物意图误导**：巡夜者始终朝危险与失踪者移动，但镜头让玩家以为她在追捕自己。
5. **烛蛾身份误导**：玩家以为烛蛾是小满的亡魂，纸张日期与新鲜折痕最终证明她仍活着。

### 5.2 公平叙诡原则

- 真相出现前，关键答案至少提前出现三次，但不被镜头强调。
- 每条线索第一次观看支持错误理解，第二次观看能得到更完整解释。
- 结局只重排已知事实，不临时增加双胞胎、梦境、人格替身等新设定。
- 主角记错的是因果与主语，不是凭空看见不存在的事件。
- 怪物行为在反转前后保持一致，变化的是玩家对行为目的的理解。

### 5.3 可二次解读的线索

| 首次所见 | 玩家容易得出的结论 | 真相后的解释 |
| --- | --- | --- |
| 开门的是一双粗糙大手，闪电后才变小 | 恐怖化的视觉演出 | 最先进入孤院的是成年小川 |
| 车内有二十三个剪影，女孩坐在末排 | 妹妹被车困住 | 小满已经安全上车 |
| 广播只说“还少一个”，不说名字 | 少的是任务目标小满 | 小川从未允许广播念出自己的名字 |
| 镜中人物比角色高，慢半拍低头 | 镜子里有怪物 | 镜中是现实中的成年小川 |
| 巡夜者每次靠近，附近都会有落物或断裂机关 | 怪物制造危险 | 她一直先于玩家赶去阻挡危险 |
| 纸蛾边缘干燥、折痕崭新 | 超自然物件不会腐坏 | 它是不久前由成年小满放下的 |
| 小川的床没有名牌 | 他已经不属于孤院 | 他主动把自己从记忆名单中删除 |
| 任务文字总用“找到她”“带她走” | 系统在发布客观任务 | 这是小川给自己的错误命令 |

### 5.4 会撒谎的任务文本

前半程的任务文字不是全知系统，而是小川的自我叙事：

- “找到她。”
- “别让巡夜者带走她。”
- “只要钟响，一切可以重来。”

取得转移名单后，烛蛾会烧掉句子中的“她”，任务变成：“找到少的那个人。”

取得新纸蛾后，任务第一次出现主语：“让小川回答。”此刻玩家才意识到，过去所有目标都刻意回避了主角姓名。

## 6. 主要角色

### 小川

- 游戏形态：11 岁，黄色雨衣，瘦弱，不说话。
- 真实年龄：35 岁。
- 表层目标：找到妹妹小满。
- 内在缺口：把获救理解成自己夺走了别人的生路，把持续自责误认为对死者负责。
- 防御方式：逃离关系、提前离场、反复确认出口、拒绝童年名字。
- 弧光：寻找别人 → 保护错误叙事 → 发现妹妹生还 → 哀悼林姨 → 面对空位 → 回应自己的名字 → 接受未来。

### 小满

- 小川的妹妹，灾难时 8 岁。
- 喜欢把废纸折成蛾子，相信“蛾子认得亮着的窗”。
- 不以幽灵身份出现。她通过纸蛾、物件记忆和最终的成年身影存在。
- 她不是等待哥哥拯救的人，而是最终把哥哥带出迷雾的人。
- 她也有成长：从“等哥哥回来完成旧约”，走到承认两人都已长大，不再要求哥哥恢复成从前的样子。
- 她有自己的成年生活，每年回到门口只是保留寻找亲人的权利，不把她写成专门治愈主角的工具人。

### 林姨 / 巡夜者

- 真实身份：孤院夜间照护者，熟悉每个孩子的名字。
- 记忆形态：身体被钟影拉长，脸是一盏扫描走廊的冷灯。
- 玩家前期认为她在搜捕孩子，后期发现她一直在找“少的那一个”。
- 不直接说教。终局中，她只把门推开，替小川挡住落下的钟摆。

### 烛蛾

- 由纸蛾、灯火与记忆组成的引路者。
- 指向互动目标，也是成长与存档的世界内表现。
- 光弱时贴近小川，光强时飞向真相，不直接代替玩家解谜。
- 真结局后变回普通纸蛾，说明超自然旅程已经结束。

### 空位

- 小川从幸存者名单中删去自己后留下的儿童残影。
- 外形与小川相同，但雨衣没有颜色、脸部没有五官、身边没有烛蛾。
- 它不主动攻击，只在镜面、车窗和积水中复制玩家动作，并逐章提前半拍。
- 终局中它走出镜面，成为唯一无法通过潜行、闪避或成长能力越过的存在。
- 它不是需要消灭的邪恶人格，而是被小川遗弃在 23:47 的自己。

## 7. 心牢规则与视觉表达

### 7.1 心牢的四条规则

1. **时间停在 23:47**：所有钟面缺少分针，雨滴在钟响时短暂倒流。
2. **道路只通向里面**：从出口离开会回到更深一层，表达小川只会逃跑、不会真正离开。
3. **空间服从错误记忆**：接送车、宿舍和钟塔被压缩在同一条不可能存在的轴线上。
4. **名字决定存在**：有名牌的床会出现孩子轮廓，没有名字的人无法被门、镜子和灯光承认。

心牢会随成长发生可观察变化：第一幕门把无法从内侧转动；第二幕后门把出现双向结构；真结局时门不再自动关闭。治愈因此通过空间规则发生，而不是只靠对白宣布。

### 7.2 世界与视觉规则

| 元素 | 表层功能 | 叙事含义 |
| --- | --- | --- |
| 雾 | 限制视野、隐藏道路 | 不愿被说出的创伤 |
| 钟 | 关卡目标、节奏与警报 | 秩序、点名和停不下来的过去 |
| 黄色雨衣 | 角色识别与暖色焦点 | 小满替哥哥扣好的最后一件东西 |
| 烛蛾 | 导航、提示、成长 | 兄妹之间仍然有效的约定 |
| 记忆余烬 | 收集物、恢复勇气 | 平凡但真实的生活证据 |
| 巡夜灯 | 敌人视野 | 被误读的寻找与保护 |
| 二十四块名牌 | 终局机关 | 每个孩子都应被点到名字 |
| 镜面与积水 | 提示现实年龄、生成空位 | 被小川排除的成年自我与儿童自我 |

色彩从冷灰、铁蓝、病绿逐步过渡到黎明的低饱和暖金。结局不突然变成明亮童话，暖色只占画面约三分之一，让治愈可信而不过度甜化。

## 8. 心理成长与玩法闭环

### 8.1 六阶段成长弧

| 阶段 | 小川的心理 | 玩家行为 | 场景反馈 |
| --- | --- | --- | --- |
| 回避 | 我只是来找人，不是回来 | 不看门外女人，进入孤院 | 成人手变成儿童手 |
| 否认 | 小满仍被困在里面 | 收集余烬、追逐女孩剪影 | 所有箭头只指向更深处 |
| 投射 | 巡夜者夺走了她 | 躲藏、逃跑、对抗探灯 | 巡夜者始终先赶到危险位置 |
| 讨价还价 | 敲响三座钟就能重来 | 修复钟坛、反复重置空间 | 钟响后场景更完整，却不能改变事实 |
| 崩解 | 小满活着，林姨是为我而死 | 失去错误目标，烛蛾熄暗 | 空位从镜面走出 |
| 接纳 | 被救不是罪，我也在名单里 | 停止逃跑、面对空位、回应名字 | 镜头升高，门第一次真正通向外面 |

成长必须由玩家完成动作触发。尤其终局不播放一段“主角想通了”的过场，而要求玩家主动停止移动、转身面对空位。

### 8.2 核心玩法闭环

探索环境 → 发现余烬 → 看见短促记忆 → 判断巡夜路径 → 潜行或闪避 → 点燃钟坛 → 选择烛蛾成长 → 打开更深区域。

### 8.3 勇气

- 勇气不是生命值，而是小川留在记忆中的稳定程度。
- 被巡夜灯持续照见会下降；进入阴影、找到余烬和完成机关会恢复。
- 归零时画面被雾吞没，烛蛾将玩家带回最近钟坛；不播放死亡动画。
- 第一版沿用“回到入口并失去一枚未投入钟坛的余烬”，后续改为明确的钟坛检查点。
- 叙诡揭露后，玩家会发现勇气下降并不是巡夜者造成伤害，而是小川抗拒记忆完整出现。巡夜灯照见他时，环境反而更接近真实。

### 8.4 三种烛蛾成长

| 路线 | 玩法效果 | 情绪表达 | 结尾动作差异 |
| --- | --- | --- | --- |
| 温灯庇护 | 降低勇气流失 | 我愿意保护脆弱 | 小川替小满挡住雨，再一起离开 |
| 无声足迹 | 提升移动与闪避 | 我愿意跨出停滞 | 小川先迈出门，再回身等小满 |
| 余烬回响 | 扩大感知范围 | 我愿意听见真相 | 小川先听见妹妹的回应，再回答自己 |

三种路线共享同一个真相与和解，不制造善恶结局。它们前期分别像保护、逃跑和追索三种应对方式，终局则被重新整合：保护脆弱的自己、走出停滞、听见完整真相。

## 9. 第一版完整关卡剧本

### 9.1 结构总览

| 段落 | 地点 | 时长 | 目标 | 情绪 |
| --- | --- | --- | --- | --- |

### 9.2 八枚记忆余烬

| 编号 | 位置 | 物件显形 | 记忆文本 | 信息作用 |
| --- | --- | --- | --- | --- |
| 01 | 雾林入口 | 黄色纽扣 | “别怕，扣好了就不进雨。” | 建立兄妹关系 |
| 02 | 接送车旁 | 半张车票 | “二十三个。还少一个。” | 建立核心谜团 |
| 03 | 宿舍门口 | 掉瓷的水杯 | “给哥哥留一口，他怕打雷。” | 证明小满在照顾哥哥 |
| 04 | 倾斜衣柜 | 旧纸蛾 | “如果走散，就跟着蛾子飞。” | 建立引路规则 |
| 05 | 机械长廊 | 铜哨 | 急促两声后，一声长音 | 暗示林姨改变搜救方向 |

### 9.3 分场脚本

#### S00 黑屏点名

- 画面：全黑，只听雨、远处发动机和二十三次极轻的木牌碰撞。
- 声音：失真女声：“二十三……还少一个。”巨大钟摆靠近，画面在落锤前切开。
- 现实层：电子屏显示 23:47。一个成年男人反复检查拆除通知、纸蛾和三处出口，却避开门外女人的方向。
- 画面：成年人的手推开锈门，闪电后变成孩子的手。门外女人被锈门遮住，玩家尚不能确认年龄变化。
- 控制权：黄色雨衣小川站在雾林入口，烛蛾从掌心亮起。
- 首个目标：“找到她。”任务框不显示发布者。

#### S01 第一枚余烬：雨衣纽扣

- 玩家只需向前走，烛蛾停在发光纽扣上，完成互动教学。
- 触碰后，画面短暂变暖：一双小手替小川扣好雨衣。
- 小满童声：“别怕，扣好了就不进雨。”
- 回到现实后，远处接送车车灯亮起一秒，又立即熄灭。

#### S02 废弃接送车

- 车门不断开合，但车内没有人。每次开门，座位数量都会少一张。
- 玩家绕过车尾取得余烬 02，第一次听见“二十三，还少一个”。
- 第一名巡夜者出现在车窗倒影中，真实场景里晚半秒才出现。
- 教学：奔跑会扩大巡夜灯范围，蹲行可穿过车灯扫动的间隙。

#### S03 候车钟坛

- 玩家投入两枚余烬。车内出现二十三个孩子的暖色剪影。
- 小川走向车门时，一个女孩剪影已经坐在最后一排，但雾遮住她的脸。
- 车门关闭，小川的剪影留在车外。玩家此时仍会误以为妹妹被留在里面。
- 第一次成长选择：“让这束光记住什么？”
- 门牌翻转，显示下一地点：“熄灯后，不许离床。”
- 车窗里第一次出现高于儿童角色的现实倒影。玩家转动镜头时，倒影晚半拍才跟随。

#### S04 沉默宿舍

- 宿舍顶灯依次熄灭。灯亮时床铺为空；灯灭时被褥下出现儿童轮廓。
- 玩家只能在熄灯阶段移动。提前移动会使所有轮廓同时坐起，巡夜者进入走廊。
- 床头水杯中取得余烬 03，听见小满给哥哥留水。
- 该记忆第一次颠倒“哥哥保护妹妹”的单向关系。

#### S05 倾斜衣柜

- 柜门内侧有两道不同高度的刻痕和一只纸蛾。
- 玩家取得余烬 04，看到小满折纸后主动爬出衣柜，一只成年人的手牵住她。
- 记忆在脸出现前被钟声截断。成年人的手在当前场景中变成巡夜者的长臂。
- 追逐开始。玩家躲进相邻阴影，巡夜者隔着柜门停留，不强制突脸。

#### S06 熄灯钟坛

- 钟坛点亮后，所有床铺同时恢复整齐，唯独小川的床没有姓名牌。
- 记忆剪影中，林姨抱起小满离开。由于镜头被门框切割，玩家暂时仍可能理解为“带走”。
- 第二次成长选择。
- 钟坛背面出现一道红围巾纤维，指向钟塔机械区。
- 任务文字短暂变成“别让她带走——”，随后又恢复“找到小满”。破折号后的宾语被心牢抹除。

#### S07 机械长廊

- 巨型齿轮按点名节奏转动：二十三次短响，一次空拍。
- 第二、第三名巡夜者分别负责横向和纵向巡逻，形成现有三敌人组合。
- 余烬 05 的铜哨触发声音记忆：两短一长。巡夜者听见后不再朝玩家移动，而是同时看向检修门。
- 玩家第一次可以通过理解声音改变敌人路线，而不是只躲避。

#### S08 红围巾与检修门

- 玩家用钟摆投下的阴影穿过长廊，在门把上取得余烬 06。
- 记忆完整显示：林姨把小满交给车上的人，听见仍少一人后立刻折返。
- 文字：“林老师回去找人了。”
- 巡夜者从玩家身后赶到，却没有抓人，只伸手推开卡死的检修门。
- 门后积水映出成年小川，旁边站着没有倒影的小川儿童形态。玩家移动时，儿童倒影开始提前半拍。

#### S09 两枚可选真相

- 余烬 07 位于接送车内侧暗格。第二钟坛点亮后，车门不再循环，玩家可原路返回取得名单。
- 余烬 08 位于终点门缝。需要让烛蛾穿过门缝，从另一侧拨开插销。
- 获得 07 后，任务文本由“找到小满”改为“找到少的那个人”。
- 获得 08 后，纸蛾上的墨迹仍未干，证明它来自今夜。任务文本中的旧句被烧掉，改为“让小川回答”。

#### S10 归名钟坛

- 第三钟坛前竖着二十四块名牌，其中二十三块亮起。
- 玩家投入最后两枚通关余烬，巨大钟面打开，露出没有指针的点名室。
- 第三次成长选择后，根据收集数进入结局分支。

#### S11 空位

- 仅在取得全部 8 枚余烬时触发。6 枚和 7 枚路线会在空位仍留在镜中时进入对应结局。
- 进入点名室前，空位从镜面走出。它与玩家使用相同移动、潜行和闪避动作，始终封住出口。
- 玩家越急于逃离，空位越靠近；使用闪避只会让双方同时交换位置。
- 烛蛾停止引路，落在地面。所有任务文字消失，只剩呼吸声和一次没有落下的空拍。
- 当玩家停止输入三秒，空位也停下，却第一次抬头看向玩家。此时互动提示出现：“看见。”
- 玩家面对它互动后，空位掀开无色兜帽，里面不是怪脸，而是十一岁小川被雨水打湿的脸。
- 小川抱住空位。两者合为一体，雨衣恢复黄色，最后一块“小川”名牌从胸口落下。

### 9.4 结局脚本

#### 结局 A：回声

条件：取得 6 枚余烬。

- 小川敲响大钟，雾短暂退去，又从门外倒灌回来。
- 广播仍说：“二十三，还少一个。”
- 烛蛾飞向来路，停在玩家遗漏记忆的方向。
- 结束文字：“有些门已经打开，有个名字还没有回答。”
- 按钮：“再听一遍。”

这是完整但未和解的第一轮结局，用于自然引导补全真相，不把玩家判为失败。

#### 结局 B：留灯

条件：取得 7 枚余烬。

- 玩家得知小满已获救，巡夜者恢复为林姨的轮廓，并打开孤院大门。
- 门外有一个成年女人撑伞等待，但两人之间仍隔着一层雾。
- 她把一只新纸蛾放在门槛上。烛蛾没有熄灭。
- 结束文字：“你已经知道她活着，却还没有叫回自己。”
- 若缺少余烬 07，女人的身份仍被雾遮住；若缺少余烬 08，门外只留下新纸蛾。两个版本分别提示尚缺的事实证据。

#### 结局 C：破晓（正史）

条件：取得 8 枚余烬。

1. 空位与小川合为一体后，点名室广播反复说：“二十三，还少一个。”
2. 玩家拾起“小川”名牌。界面同时出现“替小满回答”和“让小川回答”，前者逐字熄灭。
3. 玩家把名牌放入第二十四个位置，互动按钮由“点燃”变为“回应”。
4. 小川发出全游戏第一句自己的声音：“小川在。”
5. 第二十四块名牌亮起。所有巡夜灯转为暖光，林姨恢复普通人的身形。她不说话，只替小川挡住落下的钟摆并推开出口。
6. 镜头穿过门时缓慢升高。孩子的手变回成年人的手，黄色雨衣变成被他抱在怀里的旧衣物。
7. 门外，成年小满拿着与余烬 08 相同的新纸蛾。开场时被玩家忽略的女人就是她。

最终对白：

> 小满：小满也在。
>
> 小满：哥，这一次，你没有迟到。
>
> 小川：一起回家吧。

两人取下林姨的红围巾和二十四块名牌，并肩离开。没有人回头砸毁大钟。日光照入后，钟摆自然停止，烛蛾落回门槛，成为一只普通纸蛾。

片尾字幕前最后一句：

> 天亮时，他们没有带走那口钟，只带走了彼此的名字。

### 9.5 成长路线的片尾差异

真相和重逢不变，只改变最后十秒的动作：

- 温灯庇护最高：小川先把旧雨衣披到小满肩上，两人共撑一把伞。
- 无声足迹最高：小川先走出雾，回身伸手，小满跟上。
- 余烬回响最高：小川先听见“小满也在”，再回答“小川在”。
- 三者相同：两人同时提起纸蛾，让它停在门牌之间。

- 小满：两短一长的轻哼，与林姨铜哨、机关节奏相同。

## 11. 怪物与关卡规则

### 巡夜者

- 视觉：瘦长照护者轮廓，面部像旧式探灯，手臂过长但不出现身体破坏。
- 行为：固定巡逻、声音调查、灯光锥感知。不会无规则瞬移。
- 反转伏笔：钥匙串、红围巾、发现玩家后先伸手而非挥击。
- 真相揭露后，同一套动作被重新理解为引路、开门和遮挡危险。

### 空位

- 只在反射面和终局出现，不参加常规巡逻。
- 复制玩家全部能力，因此不能被技能数值压制。
- 谜题答案是停止输入、转身注视、主动互动。
- 玩家失败时不重置关卡，只回到空位出现前，避免情绪高潮被重复操作冲淡。

### 失败反馈

- 被持续凝视：雨声变大，孩子呼吸急促，环境边缘退入雾中。
- 勇气归零：烛蛾包住镜头，将玩家带回检查点。
- 不使用“你死了”。提示为：“这段记忆暂时关上了门。”

## 12. Steam 版完整扩写

Steam 版沿用第一版真相，把被压缩的空间和人物关系扩展为五章。

| 章节 | 时长 | 核心地点 | 核心玩法 | 剧情推进 |
| --- | --- | --- | --- | --- |
| 序章：雾林接送站 | 35～45 分钟 | 山路、候车棚、废弃接送车 | 光线潜行、车内座位谜题 | 建立“二十三，还少一个” |
| 第一章：沉默宿舍 | 45～60 分钟 | 寝室、医务室、储物阁 | 明暗节奏、衣柜藏身、床牌排序 | 玩家误认小满被巡夜者带走 |
| 第二章：雨水之下 | 50～60 分钟 | 洗衣房、锅炉房、排水检修道 | 水位、蒸汽、搬运与声音引导 | 发现孩子们的真实撤离路线 |
| 第三章：纸蛾温室 | 40～50 分钟 | 废弃教室、温室、屋顶连廊 | 烛蛾协作、风向与影子拼图 | 发现成年小满持续回来的证据 |
| 第四章：最后一次点名 | 60～75 分钟 | 钟塔外墙、机械心室、点名室 | 攀爬、齿轮、复合追逐、名牌终局 | 林姨救援真相与兄妹重逢 |

### 序章：雾林接送站

- 成年小川收到小满寄来的拆除通知与新纸蛾，来到约定地点，却因回避而没有认出门外的小满。
- 开场可操作段让玩家控制成年小川查看出口，但镜头不露正脸；进入锈门后无缝切换为儿童身体。
- 玩家修复车灯，让座位依次显形。最后一排的小满剪影一闪而过。
- 章节追逐中，巡夜者不是追向出口，而是逆着人流返回孤院，埋下反转。
- 章末点燃候车钟，车内出现二十三个孩子。

### 第一章：沉默宿舍

- 玩家按照旧作息恢复寝室灯光，错误顺序会唤醒被褥中的空壳。
- 新敌人“叠被人”只在摇篮曲停下时行动，会把走散的床牌重新塞回被窝。
- 医务室记录显示小川长期怕雷，小满常把自己的糖水留给他。
- 章末衣柜记忆故意截断在林姨伸手处，形成最低点：玩家以为妹妹遭到伤害。

### 第二章：雨水之下

- 玩家沿洗衣布带与排水道逆向追踪撤离路线。
- 新敌人“听钟工”没有视觉，只感知奔跑、坠物和齿轮震动。
- 双层水位谜题要求玩家先放走代表“记忆”的暖水，再进入冰冷检修道。
- 章节结尾发现二十三件儿童雨具已被转移，唯独黄色雨衣仍留在塔内。
- 玩家第一次怀疑“少一个”说的是自己。

### 第三章：纸蛾温室

- 这是全游戏最安静、最温暖的一章，为终局前提供呼吸。
- 温室里挂着不同时期的新纸蛾，纸张、笔迹和日期都属于成年后的年份。
- 玩家与烛蛾分离协作：小川移动遮光板，烛蛾借风穿过小孔打开路径。
- 无追逐段落。威胁来自雾会抹掉纸上的字，玩家需要主动为记忆留光。
- 章末完整看见成年小满在门外等待，明确她并未死去。
- 小川失去“寻找妹妹”这一支撑后，心牢开始坍塌，空位第一次在非镜面空间中出现。

### 第四章：最后一次点名

- 钟塔外墙攀爬把低位压迫感转为高处眩晕，暴雨重现但现实天空正逐渐放晴。
- 三类敌人的规则在机械心室组合，玩家需要用铜哨调动巡夜者替自己压住机关。
- 最终追逐中，林姨的巨大记忆形态看似逼近玩家，实则一次次挡住坠落构件。
- 完整回忆显示：林姨把小川推进排水道，将自己的红围巾绑在他手腕上，随后钟塔坍塌。
- 空位复制玩家全部已学能力，终局要求玩家放弃逃跑逻辑，停下并主动靠近自己的儿童残影。
- 点名室沿用第一版真结局，但增加二十四个孩子逐一回应的声音，最后由玩家回答“小川在”。
- 现实尾声中，兄妹允许危险旧址按计划拆除，将二十四块名牌和林姨的红围巾交给地方档案馆。最后一只纸蛾留在打开的围栏上。

## 15. 叙诡与情绪验收标准

- 不阅读设计文档的测试者，通关后能说出“妹妹活着，当年少的是哥哥”。
- 测试者能理解小川被困不是因为孤院不放人，而是他相信“找到妹妹才有资格离开”。
- 测试者在前半段害怕巡夜者，结尾能重新理解其行为。
- 二周目测试者能指出至少三处早已出现的真相线索，且不认为结局临时改设定。
- 至少 70% 的测试者无需文字提示，能在空位处尝试“停止并面对”。其余玩家在 20 秒后获得烛蛾落地提示。
- 真结局对白总量不超过 30 秒，但能完成情绪闭环。
- 首次可操作在开始后 10 秒内，首次余烬在 45 秒内。
- 强制惊吓为 0；紧张感主要来自动线、声音与灯光。
- 6 枚即可结束，8 枚真相完整；遗漏线索有明确回望提示。
- 竖屏与桌面端均能读清目标、记忆短句和结局字幕。
- 第一版结尾可以独立成立，Steam 版扩写不需要修改核心真相。

## 16. 制作结论

《雾钟孤院》的独特性不在“儿童逃离怪物”，而在“玩家最终发现怪物一直在寻找并保护自己”。

第一版应集中完成一件事：让玩家相信自己在帮助哥哥寻找妹妹，随后意识到一路上真正被寻找、被保护和等待的人都是哥哥自己。

玩家最终说出“小川在”，不是答对一个反转谜题，而是完成一次由自己操作的自我接纳。只有叙诡与成长同时抵达这里，《雾钟孤院》的微恐、冒险与治愈才真正属于同一个故事。

# 校验摘要

## 结果

- ZIP：`release/mist-clock-orphanage-xhs-1.3.0.zip`
- 包体：254,966 字节，低于 10 MiB 上限和 2 MiB 建议值。
- SHA-256：`48EF35A87878B1CE2029F605E10CF5BC06234B31F0F67F89D5485B8BA3351167`
- 结构：`index.html` 位于 ZIP 根目录；共 5 个允许类型文件，无多余目录层。
- 离线：无 CDN、网络请求、外部字体、外部图片或模块脚本。
- 安全：未发现 `eval`、`new Function`、WebAssembly、Worker、iframe 或外部跳转。
- 兼容：JavaScript 语法检查通过；代码保持 ES2017 / Chrome 61 基线。
- WebGL：WebGL 1；主角为黄色雨衣瘦弱男孩，包含八面尖兜帽、外扩衣摆、深色面孔开口、细长四肢、小提灯与自然步态。
- 光影：入口、宿舍与钟塔各有独立冷色方向光、雾中光束和落地亮区；角色会按所在区域投出对应方向的长影。
- 场景：雾林、废弃接送车、沉默宿舍与钟塔机械区保持低位电影视角和深色前景剪影。
- 性能：默认像素上限 180 万、DPR 上限 1.5；低档像素上限 100 万并减少雨雾粒子。

## 已实测

- `npm run build`、`npm run check`、`node --check app/assets/main.js` 通过。
- 本地资源完整性、离线能力与禁用 API 扫描通过。
- 1280×720 桌面视口：入口斜向探照光、宿舍顶灯光带、钟塔垂直光柱、人物长影和深色前景均正常。
- 390×844 移动视口：冷灰亮区、探照光束、人物长影、摇杆与动作按钮无溢出。
- 390×844 移动视口：主角正面、背面均完成截图检查，无方形背包或方块躯干。
- 触屏摇杆推动角色进入感知范围；互动提示出现，余烬拾取后计数从 0 更新为 1。

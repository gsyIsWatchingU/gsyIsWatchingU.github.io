# 雾钟孤院

面向小红书小工具容器的原创 3D 暗黑童话冒险原型。

完整世界观、心理成长、叙诡线索、分场剧本、三结局与 Steam 扩写方案见 [`game-design-script.md`](./game-design-script.md)。

## 已实现

- 轻量 WebGL 1 第三人称 3D 场景，无网络依赖。
- 原创雨衣男孩 GLB 模型：瘦弱儿童比例、完整兜帽与衣褶贴图，替代程序化积木网格。
- 免费版模型采用代码驱动的重心起伏与身体摆动；骨骼动画待后续使用可用的免费绑定方案补充。
- 冷灰雾林、废弃接送车、沉默宿舍与钟塔机械区组成连续环境叙事。
- 低位电影镜头、三组冷色方向光、雾中光束、落地光斑和角色提灯共同承担视觉引导。
- 内置 Noto Serif SC 中文字体子集，标题、按钮与 HUD 离线统一渲染。
- 弱化常驻 HUD；任务和交互提示仅在状态变化或靠近目标时出现。
- 触屏摇杆、镜头拖拽、潜行、闪避、互动；兼容键盘操作。
- 余烬采集、三座钟坛、巡夜者感知、勇气值与失败回退。
- 烛蛾永久养成：庇护、敏捷、感知三条分支写入 `localStorage`。
- 根据网络状态自动匹配画质，并结合实时帧率降级；无需手动选择。
- 页面隐藏暂停、WebGL 丢失处理与 2D 叙事兜底。

## 操作

- 移动端：左侧摇杆移动，拖动场景转镜头；右侧按钮潜行、闪避、互动。
- 桌面端：`WASD` / 方向键移动，`Shift` 潜行，`Space` 闪避，`E` 互动，`Esc` 暂停。

## 目录

- `app/`：可直接运行、审计和打包的离线产物目录。
- `assets/concepts/`：原创角色三视图概念稿。
- `release/`：小红书小工具 ZIP 交付包。
- `validation-summary.md`：校验记录与未实测项。
- `third-party-licenses.md`：第三方字体来源与许可。

- 打开 `index.html`（需 HTTP 服务），可检查站立、行走、坐下、侧躺与点击回应。
- 菠萝屋入口：`/pineapple-house.html?cat=furry&privacy=1`，隐藏个人信息。
- 参考用户提供的站立、坐姿、侧躺照片；模型导图为图像工具生成，非网页截图。
- 形体与贴图由自有 L20 / Hunyuan3D-2.1 生成；使用直接阶段脚本，未使用第三方建模 API。生成表面闭合修补后再次 GPU 上色，CPU 仅修补、减面、绑定与导出。

- 正式默认入口继续使用现有模型；本候选确认后再替换。原始参考照片和排查用网格不纳入提交。

## 实际制作来源

六件模型为派大星、扶手椅、紫床、冰箱、炉灶、老电视。单件参考由自有 L20 的 Z-Image-Turbo 生成；四张 T4 执行已部署 Hunyuan3D-2.1 Shape；两张 L20 执行 Hunyuan3D-Paint-2.1；Blender 4.5 修整背景残片、比例、坐标与材质。没有修改或重启生产服务。

阶段 ID 是本次直接运行后端的追踪标识，并非 Forge3D HTTP API 返回的任务号。参数、输入/Shape/Paint/运行时 SHA-256 在 `manifests/`；原始参考在 `sources/`；最终 GLB 在 `assets/patrick-reference/models/`。原始高模、Paint 输出和 `.blend` 留在任务生产目录，不加入网页下载。

派大星 Shape 的手臂与腹部粘连，自动热权重产生错误变形，已拒绝。最终由 Blender 重拓扑连续身体、手臂、眼睛和脚；保留 GPU 花纹短裤、眉嘴纹理，重投影并烘焙身体纹理，导出 **9 骨蒙皮 + idle/wave 两动作**。不是未经修整的自动生成模型。

海报/相框直接取自用户布局图，透视校正后贴合内壁；其余建筑、交互屏幕和小装饰为独立 Three.js 修整。仅这些画作使用平面图像，整屋不是参考图片的平面投影。

入口：`http://127.0.0.1:8769/pineapple-house.html`。首屏直接读摘要；六项导航联动房间与正文，模型失败不阻塞履历。

| 房间 | 内容 |
| --- | --- |
| 客厅 | 三类技能与实习、项目证据 |
| 天台 | 字节实习与四项成果 |

## 验证

- 1440×900、390×844：首屏、六项导航、房间点击、技能证据、原图、放大、返回、Esc、刷新恢复通过；无横向溢出。
- 默认 1280×720 窗口也可在首屏看到摘要和简历入口。手机截图 API 实际输出 390×843，未补边修改。
- 墙面证书点击打开 MathorCup 原图；11 张原图逐一加载成功。图书馆书目签点击进入 Coffee Research 详情。
- 鼠标拖拽和滚轮改变真实相机坐标；移动端为浏览器尺寸模拟，双指及实机性能仍需实机复核。
- 临时夹具注入扶手椅模型及证书贴图失败：显示资源名称；正文仍可读；重试从 12 模型 / 10 贴图恢复至 13 / 11，并执行待定房间近景。
- 禁用 WebGL 的夹具显示明确提示，实习正文与导航可用；正常预览控制台无错误或警告。夹具仅在忽略目录 `tmp`。
- 原件哈希、资源路径、构建、源码语法和 `git diff --check` 通过。结果在 [browser-results.json](browser-results.json)，截图在 [screenshots](screenshots/)。

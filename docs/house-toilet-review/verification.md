# 马桶里的项目

- 点击房间只进入浴室；再点实体马桶或“憋出来的项目”标签。
- 废弃脑花 → 打码团 → 卡通便便 → 七个真实项目；可直接跳过动画。
- 两个简历项目、五个独立产品；三个已有演示入口。清理按钮可从项目列表或详情使用，关闭并清空效果后留在浴室。

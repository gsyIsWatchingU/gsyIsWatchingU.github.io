# 极品项目集

- 进入浴室后点马桶，只弹出废弃脑花、打码团与卡通便便。
- 点击便便下方黄色“极品项目”按钮，才打开右侧项目集；按钮明确显示“👆 点击查看”，手机使用底部阅读面板。
- 六个分类：ETMS、write-here、ai-project-hub、算法八股学习网站、skill-atlas、cli-list。每次只显示所选项目，介绍、实现与成果直接在面板内阅读。
- 一键打扫独立于项目集，并注明“清理马桶弹出的所有物品”；清除脑花、打码团与便便并收起项目集，保持浴室镜头。
- 项目集只有“收起”按钮，收起保留弹出物与所选项目；Esc 先收起项目集，再清理物品。刷新回到干净首屏。
- AI Project Hub 与 Skill Atlas 文案核对本地仓库 README；沿用其他项目的真实履历与截图，不新增未经核对的在线入口。

本轮验证：实际桌面 1280×720、手机视口 390×844，点击提示、清理范围、面板内没有打扫按钮、收起保留物品和项目选择、动画中清理及无横向溢出。结果见 `cleanup-results.json`；最新截图包含 `click-hint` 与 `independent-clean`。此前六类切换等结果见 `premium-results.json`，旧版证据保留。

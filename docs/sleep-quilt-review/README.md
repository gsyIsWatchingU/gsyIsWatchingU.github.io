# 睡觉被子修复

## 脚部翻折补修

- 原因：睡眠动作直接覆盖 GLB 腿骨原本的 180° 旋转，使膝盖和脚踝翻向裤子；上一轮落床检查漏查了骨骼朝向。
- 改为初始姿态叠加动作，小腿、脚掌保持初始旋转；被子贴合范围包含鞋子。
- 修复前腿部方向读数为 -1；修复后五阶段均为正，最低约 0.8。441 个鞋面采样点全部被盖住，最小间隙约 33mm；床垫接触仍为 7mm。
- `legs-before/`、`legs-after/` 为真实 Chrome 截图与读数；`legs-geometry.json` 为几何测量。手机为视口模拟。

## 被子修复记录

- 原因：立即隐藏原被子，换成无厚度的 625 顶点薄片；弧度与身体不符。重复睡觉还会误识别动画被子。
- 修复：复用原被子 1225 顶点、圆角、厚度和 UV；到床边才同步切换，连续拉开与盖回。按身体各段表面形成弧度，床尾平铺，头部略靠枕头。
- 浏览器：真实鼠标、原生动作选择，桌面五阶段、恢复原被子和手机视口重复睡觉，共 8 条记录；脚本异常和场景资源失败均为 0。
- 公网：同样 8 条记录通过，3 个关键文件内容哈希与本地一致，Pages 发布成功；证据见 `live/`。
- 几何：真实蒙皮背部与床垫间隙 7mm，角色在床垫范围内；原网格、UV、重复睡觉与中断恢复检查通过。
- 证据：`before/` 是复现；`after/` 是修复后截图与记录，`geometry.json` 是模型测量。手机为视口模拟，实机未测；待用户审看。
